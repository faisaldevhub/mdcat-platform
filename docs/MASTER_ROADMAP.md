# Important Product Rules

Rules:

* Do not jump randomly between features
* Complete sprint before starting new sprint
* Keep architecture modular
* Maintain centralized access control
* Reuse existing services
* Avoid duplicate business logic

---

# Product Philosophy

The platform should evolve in this order:

1. Strong Learning Core
2. Student Retention
3. Monetization
4. AI Intelligence
5. Enterprise Scaling

Never reverse this order.
